# Equality — значки

Общий каталог значков для мода **Equality**. Здесь лежат картинки, список значков и кто какой носит.
Приложение читает только `badges.json` (его собирает бот, руками не править).

## Файлы
| Файл | Что это |
|---|---|
| `images/<id>.png` | Картинка значка, имя = id значка |
| `catalog.json` | Каталог: id, название, автор, описание |
| `wearers.json` | Кто что носит: id аккаунта → id значка |
| `badges.json` | Собирается автоматически из трёх выше, его читает мод |

## Как получить значок для всех
1. В моде сделайте значок локально и проверьте, как он выглядит.
2. Нажмите «Отправить на модерацию» — откроется форма заявки здесь.
3. Модератор проверяет и ставит метку `approved`. Бот добавляет картинку и запись в каталог.
4. Чтобы носить значок, подайте заявку «Надеть значок» (id аккаунта + id значка).

Подробности: [docs/FORMAT.md](docs/FORMAT.md), [docs/MODERATION.md](docs/MODERATION.md).
Никаких токенов и паролей в приложении нет: заявки идут через обычные GitHub Issues.
