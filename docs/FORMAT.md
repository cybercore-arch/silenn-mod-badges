# Формат файлов

## images/<id>.png
PNG, не больше 256×256 пикселей, не больше 100 КБ. Имя файла = id значка.

## id значка
Строчные латинские буквы, цифры и дефис, 3–32 символа, например `star-2026`.

## catalog.json
```json
{"badges": [{"id": "star-2026", "title": "Звезда", "author": "nick", "description": "За помощь проекту"}]}
```

## wearers.json
```json
{"users": {"6812345678901234567": "star-2026"}}
```
Ключ — числовой id аккаунта TikTok (только цифры), значение — id значка из каталога.
Один аккаунт — один значок.

## badges.json (собирается ботом)
Формат, который читает мод: у каждого значка `id`, `image` (`images/<id>.png`), `title`, `text`, `users`.
