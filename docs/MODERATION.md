# Правила модерации (черновик)

Одобрять нельзя:
- чужие логотипы, персонажей и знаки, на которые нет прав;
- оскорбления, 18+, политическую агитацию, угрозы;
- значки, выдающие себя за официальные (TikTok, администрация, «верифицирован»);
- картинки с чужими личными данными.

Порядок: проверить картинку и описание → поставить метку `approved` (или закрыть с причиной).
Метку может ставить только модератор с правами записи. Одобрено — значит бот сам внесёт изменения.
Жалобы на уже одобренные значки подаются формой «Жалоба», модератор убирает значок правкой файлов через PR.

## Что автоматически, что вручную
- «Надеть значок» — применяется автоматически, без модератора (только значки из каталога, один аккаунт — один значок).
- «Новый значок» — только после метки `approved` от модератора. Без метки бот ничего не добавит.
